## Before you start

Your coach or trainer sends you a **10-character invite code**, usually by text.
One code connects one athlete to one coach. If you have more than one athlete,
you need a code for each.

## Connecting

1. Open the **Teams** tab.
2. Next to **Coaches**, tap the **+** (it reads **Manage** and **+**). The
   **Connect a coach** card opens.
3. Under **For**, tap the athlete this code is for. **+ Add** creates a new
   athlete if they are not listed yet.
4. Paste or type the code into **Invite code**. There is a **Paste** button.
5. Enter **Your phone number** — the number your coach has for you. It has to
   match what the coach entered.
6. Tap **Connect**.

## When it worked

On the Teams tab the athlete's row under **Coaches** shows a green dot for each
connected coach or trainer — for example "• Coach • Trainer". Their sessions
start appearing under **Sessions** and on Home.

## Managing connections

**Manage** next to Coaches lists every connection for the selected athlete.
Disconnecting ends what that coach can see — see
