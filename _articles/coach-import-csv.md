Have your roster in a spreadsheet? Import it in one go.

## Steps

1. Open the **Teams** tab and tap **Add Athlete**.
2. At the top, tap **Add multiple athletes from a CSV file**.
3. Tap **Get the template**, open it in Numbers, Excel or Google Sheets, and put **one
   player per row**. **Athlete Name**, **Parent Name** and **Parent Phone** are required.
4. Put the team in the **Group** column. A team you don't have yet is created for you.
5. Save it **as CSV**, then tap **Upload CSV** and pick the file.
6. Check the preview: **New** will be added, **Already here** is skipped, **Needs
   fixing** says which row and why.
7. Tap **Add**.

## Nothing is sent

Importing only adds players. **No invites or messages go out.** Send each family their
invite when you're ready — see
[inviting a parent]({{ '/teamassist/invitations/' | relative_url }}).

## If the file won't load

- **"That file is missing the … column."** Start again from **Get the template**.
- **"That file is not text."** It was saved as .xlsx or .numbers; export it as CSV.
