## Add images

- **Drag and drop:** drag image files onto **Drop source images here**.
- **Or browse:** click **Browse Files**, pick one or more images, then click **Choose**.
- **Many at once:** you can add several files in one go.

## What it reads

- **JPEG** (.jpg, .jpeg)
- **PNG** (.png)
- **GIF** (.gif)
- **BMP** (.bmp)
- **TIFF** (.tif, .tiff)
- **TGA** (.tga, .targa)
- **PSD** (.psd)
- **OpenEXR** (.exr)
- **WebP** (.webp)
- **HEIC** (.heic)
- **HEIF** (.heif)

## Conversion

- **Starts on its own** when you add files.
- **Start** converts anything still **Queued**.
- **Each row** in **Files** shows **Queued**, **Converting**, **Completed** or **Failed**.
- **The counts** on the left show how many are **Queued**, **Converted** and **Failed**.

## File names

- **Same name, new ending.** `photo.jpg` becomes `photo.png`.
- **No overwriting by default.** If `photo.png` is already there, the new one is `photo 2.png`.
- **To overwrite instead,** turn on **Replace existing files**.
- **Same file twice:** a file with the same name as one already in the list is not added again.

## Try failed files again

- **Click Reset Failed.** Failed files go back to **Queued**.
- **Then click Start.**

## Start fresh

- **Click Clear** to empty the **Files** list.
- **Your PNGs stay** in the output folder.
