## A "Conversion Problem" message

The app shows a box called **Conversion Problem**. What it says:

- **"No supported image files were selected."** None of the files are a type it reads. See the list in [Convert images]({{ '/converttopng/convert-images/' | relative_url }}).
- **"Skipped … unsupported file(s)."** Some files were added. The others are not a type it reads.
- **"Could not read …"** Your Mac can't open that image. Try saving it again from the app that made it.
- **"Unsupported TGA file"** or **"Malformed TGA file"** — that TGA file is a kind the app can't read, or it is damaged.
- **"Could not write … Check that the selected folder is writable."** The app can't save there. [Choose another folder]({{ '/converttopng/choose-output-folder/' | relative_url }}).
- **"The output folder was selected, but could not be saved for future launches."** It will work now. Pick the folder again next time.

## A file says Failed

1. **Read the line** under the file name. It says why.
2. **Fix the cause.** For example, pick another output folder.
3. **Click Reset Failed.**
4. **Click Start.**

## A file didn't show up in the list

- **Same name:** a file with the same name is already in the list. Click **Clear** and add it again.
- **Not supported:** the file isn't a type the app reads.

## I can't find my PNGs

- **Look under Destination.** It shows the full path to your PNGs.
- **Numbered names:** if a file was already there, the new one ends in a number, like `photo 2.png`.

## Buttons are greyed out

- **While converting,** most buttons are off. Wait for it to finish.
- **Start** is off when nothing is **Queued**.
- **Reset Failed** is off when nothing failed.
