## Run the search

1. **Click Find File Type** at the top.
2. **Pick a type:** **Images**, **Videos**, **Audio**, **Documents**, **Archives** or **Custom…**.
3. **Optional:** set a **Size** limit.
4. **Click Search.**

## Size filter

- **Any size** — no limit.
- **At most** — this size or smaller.
- **At least** — this size or bigger.
- **Between** — between two sizes.
- **Units:** **KB**, **MB** or **GB**, counted the same way Finder does.
- **Works in every mode.**

## Video resolution

- **Shows up** when the type is **Videos**.
- **Res:** **Any**, **SD**, **720p**, **1080p**, **1440p**, **4K** or **8K**.
- **Then pick** **or higher**, **exactly** or **or lower**.
- **Short side counts.** A tall phone video is graded the same as a wide one.
- **Videos it can't read** are left out when a resolution is set.

## Custom file types

- **Pick Custom…**
- **Type the endings,** like `jpg, png, mov`.

## Results

- **Sorted by name.**
- **Each row** shows the name, folder, size and date changed.
- **Right-click a row** and choose **Show in Finder** to see it.
